# Currículo Online para Hospedagem no GitHub

Repositório com código fonte para o meu currículo online e portfólio pessoal.

**[Clique aqui para acessar o site](https://rodrigoraupp.github.io/online_curriculum/)**

## Descrição

O projeto utiliza um template de currículo online para hospedagem no GitHub Pages desenvolvido por James Grant ([link do repo](https://github.com/sproogen/modern-resume-theme)). O template é construído em Jekyll, que gera sites estáticos para o GitHub Pages.

## Tecnologias

- [rbenv](https://github.com/rbenv/rbenv)
- Ruby versão 3.3.0
- Markdown & YAML
- HTML/CSS & JavScript
- GitHub Pages

## Utilização do Jekyll

1. Instalação do rbenv
2. Instação das dependências do Gemfile
```
bundle install
```
3. Inicialização do localhost
```
bundle exec jekyll serve
```
